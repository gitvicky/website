For each served output, with prediction \(\hat y\) and label \(y\) on \(n\) calibration points, the score is \(s_i = |y_i - \hat y_i|\). The half-width is the \(k\)-th smallest score, with \(k = \lceil (n+1)(1-\alpha) \rceil\) and \(\alpha = 0.1\). The interval is \([\hat y - q, \hat y + q]\). If calibration and test points are exchangeable, the interval covers a new label with probability at least \(1-\alpha\). The probability is marginal, over both the calibration draw and the new point. MAPIE’s prefit SplitConformalRegressor computes \(q\), and the code checks each value against the exact rank.

The prediction is the one each guard serves. - Transport. The prediction is the members’ mean in training space, \(t = \operatorname{sign}(Q)\log(1 + |Q|)\). A half-width \(q\) spans a factor \(e^{q}\) on \(1 + |Q|\). - EC. The prediction is the bounded per-MW output. Its central 90% range, which includes both random draws, is stored beside each coverage. Direct ELU pilot

A separate proof graph replaces the ELU decomposition with a direct convex relaxation. For alpha=1, let \(f(x)=x\) for \(x\ge0\) and \(f(x)=e^x-1\) otherwise. On a finite interval \([l,u]\), the tangent at \(t\) gives \(f(x)\ge f(t)+f'(t)(x-t)\), and convexity gives \(f(x)\le f(l)+(f(u)-f(l))(x-l)/(u-l)\). Point intervals use the local derivative; positive intervals are exactly linear. The fixed tangent uses the interval midpoint clipped to \([-1,0]\), with exact handling for point and positive intervals. This choice is valid but does not optimize tightness.

The saturated head has the equivalent expression \(f(1-\operatorname{ReLU}(-s))-f(1-\operatorname{ReLU}(s))\). Each term is in \([-1,1]\), so the expression retains the structural range \([-2,2]\) without subtracting unbounded linear terms. Input preprocessing, normalization, weights, heat-output ReLU and inverse signed-log remain those of the saved model. The direct-ELU operator is used only by the separate experimental proof runner.
