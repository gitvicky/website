decision measurement Entry 71 · milestone JOREK (alongside M4)

Case (b) is the physical case of the JOREK stability work: the TORAX ITER hybrid state at the end of its ramp-up simulation, whose pedestal comes from the toolkit’s own pedestal model. JOREK solves its own equilibrium from the pressure, taken from TORAX’s density and temperatures, and from FF′, derived from TORAX’s current density with the bootstrap current included.

Why the tolerance changed

The first solve missed the tolerance of entry 67: plasma current I_p came out high (first row of the table below), and so did core q. The cause is structural. TORAX evolves the current on a fixed geometry taken from the CHEASE EQDSK, so its state is not itself a Grad–Shafranov equilibrium. An equilibrium with the same pressure and current density has different flux surfaces, and therefore different q.

The owner chose the recommended option of OQ-40. FF′ is multiplied by one factor so that I_p equals TORAX’s. Acceptance is entry 67’s current tolerance, with the pressure as a function of normalised flux equal to TORAX’s by construction. The q difference from TORAX is reported, not tested. This keeps TORAX’s pressure pedestal and the shape of its current profile, which drive the edge modes. The alternatives were to tune FF′ until q matched, which changes the current profile, or to build a self-consistent free-boundary state first, which is a larger piece of work.

What happened

The Grad–Shafranov iteration did not converge as first set up. Without under-relaxation, every case (b) solve cycles between two states, with the magnetic axis moving back and forth each iteration. This was already true of the first solve, and we didn’t flag it then. Case (b)’s FF′ is hollow, because the ramp-up current has not yet reached the core, so the axis is weakly pinned. JOREK’s under-relaxation option, which mixes each new flux half and half with the previous one, converges it.

A converged solve at FF′ × 0.952 gives a higher current than the stalled one at the same factor, so the stalled solves could not be used to set the factor. The accepted case directory is regenerated from the generator’s recipe and matches the accepted solve byte for byte. The same settings converge on the doubled grid, so the grid check can reuse them. These checks compare JOREK’s output with TORAX’s numbers using our own scripts, so they are not independent of the author.

The q difference is largest in the core, where q_min is higher than TORAX’s. This matters for the next scan: the case (a) core modes of entry 68 sat at a q minimum just above 1. Case (b) is unlikely to have them.

Where this stands: under OQ-41, case (b) has up to five one-node jobs. The first is the n-scan (entry 72).
